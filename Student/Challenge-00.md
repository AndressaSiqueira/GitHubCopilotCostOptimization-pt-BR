# Desafio 00 - Pré-requisitos e linha de base

**[Início](../README.md)** - [Próximo desafio >](./Challenge-01.md)

## Introdução

Obrigado por participar do What The Hack de Otimização de Custos do GitHub Copilot. Antes de começar a otimizar, você precisa configurar seu ambiente para medir com precisão os custos de uso do GitHub Copilot. Este desafio estabelece sua linha de base — a medição do "antes" com a qual todos os desafios seguintes serão comparados.

Entender para onde vão os créditos é essencial para a otimização. Neste desafio, você confirmará que a cobrança baseada em uso (UBB) está ativa, aprenderá a ler o detalhamento de tokens no VS Code e concluirá uma tarefa de programação de referência para registrar seu gasto inicial de créditos.

## Descrição

Seu instrutor fornecerá um arquivo Resources.zip que contém uma base de código inicial para este hack. A base de código está intencionalmente configurada com configurações pouco otimizadas do GitHub Copilot — você as otimizará nos próximos desafios.

Conclua as seguintes etapas de configuração:

1. Extraia o arquivo Resources.zip para sua estação de trabalho local
2. Abra o Visual Studio Code e instale/atualize a extensão GitHub Copilot para a versão mais recente
3. Verifique se sua assinatura do GitHub Copilot tem a cobrança baseada em uso (UBB) habilitada, consultando suas configurações de cobrança
4. Habilite a visibilidade do uso de tokens no VS Code:
   - Abra o painel Saída (Exibir > Saída; View > Output na interface em inglês)
   - Selecione "GitHub Copilot Chat" na lista suspensa
   - Verifique se você consegue ver as contagens de tokens e o uso de créditos por interação
5. Confirme que você consegue acessar o painel de uso do GitHub Copilot para visualizar o gasto acumulado de créditos
6. Abra a base de código inicial no VS Code e familiarize-se com sua estrutura

## Critérios de sucesso

Para concluir este desafio com sucesso, você deve ser capaz de:

- Verificar que a cobrança baseada em uso (UBB) está ativa em sua assinatura do GitHub Copilot
- Demonstrar que o painel Saída do VS Code mostra o detalhamento de tokens das interações com o GitHub Copilot
- Mostrar que você consegue acessar o painel de uso do GitHub Copilot e visualizar seu consumo atual de créditos
- Verificar que a base de código inicial de Resources.zip está aberta no VS Code
- Demonstrar que você concluiu a tarefa de programação de referência e registrou o gasto de créditos
- Mostrar suas medições documentadas de linha de base, incluindo o total de créditos e a abordagem utilizada
